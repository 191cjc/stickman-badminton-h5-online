## Delivered application contracts

- Exactly seven reachable original multiplayer roles: `joe`, `nadia`, `harry`,
  `toaster`, `pirate`, `top-hat`, `red`. Registry attributes use the source
  movement/jump/power order. Robot, Timmy, practice, AI, campaign and unlocks are
  excluded from the live product; frozen reference code remains untouched.
- Adult numerical geometry is source-checked before sharing a family. Each role
  has separate original body/attachment sets and previews. Pirate includes
  shape220/depth21. Toaster uses dedicated swing geometry, human jump, pre-bob
  contact origin,27-frame serve and frame8 release with unscaled servePoint.
- Authority/prediction share one player step. The server owns shuttle, collisions,
  score and results. Joe source-value and timing regressions remain applicable.
- Protocol3 / `badminton-v3` / `flash-90302-v2`. Strict queue character enum,
  immutable queued/seat roles, idempotent same-role queue, explicit changed-role
  error, same-role opponents and retained-seat character restoration. Legacy
  v1/v2 connections are rejected before guest/socket/seat binding.
- Presentation journal is separate from gameplay snapshots/restoration, with
  monotonically increasing match IDs,128-group cap and30-tick retention. Separate
  cosmetic RNG cannot change gameplay RNG, ball or score. Original tail pairs
  are emitted after speed computation and before collision resolution.
- Client Effects aligns source events to authority ticks, deduplicates journals,
  expires late transients, skips old/reconnect audio, and runs particles/result
  cosmetics at60Hz independently of RAF. Natural seven-point result has one
  cheer, continued bounded confetti and Toaster result bob/smoke. Abnormal results
  have explicit project reasons and do not borrow natural-win celebrations.
- Original sound buffers allow overlapping SFX, with32-voice cap, gesture unlock,
  mute/M, looping background music, scene cleanup and isolated fetch/decode
  failure. Audio loading cannot block a playable court; an early mute gesture
  does not prevent later-arriving resources from decoding.
- Both players use A/D or arrows, W/Up jump, S/Down/Space hit/serve, M mute,
  Esc authenticated leave. Input release, identity, expiry and room ownership
  remain with the existing owners.

## Fidelity limits and follow-ups

- Source-derived values and tests are not unchanged-SWF execution evidence.
  Browser/Ruffle comparison and physical dual-computer responsiveness are
  separate pending checks; no latency claim is made.
- Cosmetic RNG separation preserves source distributions/materials, while
  intentionally changing original global Math.random coupling and particle
  random order across clients. RGB's inclusive256 edge follows AS3 shift/OR
  packing, with no native Flash pixel measurement yet.
- SVG filter/export rounding, browser MP3 decoding and original seek/encoder
  behavior may differ from native Flash. Original filter trees and exact MP3
  payloads are retained, but this is not a claim of pixel/audio identity.
- Background46 currently loops with mute/scene cleanup. The original instruction
  scene's ENTER_FRAME volume fade is not reproduced; its parameter2 and
  `1/(2*30)` per-call step should not be described as a verified2-second fade.
- Source rematch up/over artwork is wired to accessible `#start`; matching again
  creates a new online room rather than resetting the same local opponents.
  Source More Games button art is exported without introducing an external
  action. Chinese state/result labels and seven-role selection remain native
  DOM adaptations and need browser layout verification.
- Production remains on its earlier release until the main session completes
  review and coordinated frontend/backend publication. No unrelated routes,
  services, frozen source files or source rights statements were changed here.
